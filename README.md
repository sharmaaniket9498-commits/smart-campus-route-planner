# 🚀 Smart Campus Route Planner

## 🌐 Live Demo

[🚀 Open Smart Campus Route Planner](https://smart-campus-route-planner.onrender.com)

A campus route-planning application featuring graph algorithms, route comparison, and an interactive graph explorer.

## ✨ Features

- Dark dashboard with yellow accents
- Interactive start and destination selection
- Dijkstra, BFS, A*, and Floyd–Warshall algorithms
- Route comparison by distance, estimated time, and cost
- Walk, Bike, Car, and Bus sample modes
- Animated route visualization and step-by-step directions
- Saved places and local JSON persistence

## 🛠️ Technologies

- Python
- CustomTkinter
- Graph algorithms
- JSON

## ▶️ Run Locally

```bash
python -m pip install -r requirements.txt
python app.py
```

## ⚠️ Disclaimer

Distances, travel times, and costs are illustrative sample estimates. The application does not provide live GPS, traffic, or real-world navigation data.
