PROJECT REFERENCE

Algorithms & Concepts

How the route planner works.

WEIGHTED SHORTEST PATH

Dijkstra’s Algorithm

Finds the minimum-total-weight path from a start node to a destination when edge weights are non-negative. The selected weight can represent time, distance or estimated cost.

UNWEIGHTED SEARCH

Breadth-First Search (BFS)

Explores a graph level by level. It finds a path with the fewest edges, but that path is not necessarily the shortest by distance or time.

HEURISTIC SEARCH

A* Algorithm

Combines the cost already travelled with a heuristic estimate of the remaining cost to guide its search toward the destination.

ALL-PAIRS PATHS

Floyd–Warshall Algorithm

Computes shortest-path costs between every pair of nodes. It is useful when many different source–destination queries need to be answered.

GRAPH MODEL

Weighted Graph

Each place is represented as a node. Connections between places are edges, and each edge stores sample distance, time and cost values.

LIMITATION

Sample estimates

This project uses illustrative connections and estimates. It does not use live traffic, GPS tracking or a live road-routing service.
